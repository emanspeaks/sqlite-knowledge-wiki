# Software design description

The architecture (%[SWE-057]) and detailed design (%[SWE-058]) of the software, after handbook topic 5.13; the interfaces, as an interface design description (topic 5.02) here or of their own. Each component is an item of the type `design`, `DES-001` and on, linked by `satisfies` to the requirements it meets; the code that implements it cites it.

## Design and trade decisions

The decisions that hold for the whole software, and the trades that led to them.

## Architecture

The components and how they relate; the review of the architecture (%[SWE-143]).

## Components

For each: what it does and how it meets its requirements (algorithms, data structures), its inputs and outputs, and its concept of execution (data and control flow, timing).

## Interfaces

For each interface: its type, data elements and their layout, protocols, and the safety features of its design.

## Resources and rationale

The planned use of computer resources; the reasons for the design, its assumptions and limitations.
