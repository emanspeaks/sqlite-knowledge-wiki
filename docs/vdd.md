# Version description

What a release of the software is (%[SWE-063]), after handbook topic 5.16; one for each release.

## Identification

The system and software, with their version and release numbers.

## Contents

The executable software and the files to install it; the life cycle data that defines it; archive and release data.

## Building

How to build it from source, and the checks of the integrity of source and object code.

## Changes

The change requests and problem reports implemented since the last release, and those still open, with workarounds.

## Checks

Confirmation that the release was scanned for security defects and checked against the coding standard (%[SWE-135], %[SWE-185]).
