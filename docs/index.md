# Software documents

The documents and records of the project's software, under NPR 7150.2D as the NASA Software Engineering Handbook (NASA-HDBK-2203) reads it. Each says which requirements it answers; the [Requirements Mapping Matrix](rmm.md) shows how every requirement the project's class invokes is met. The NPR itself, and the handbook's reading of each requirement, are in `standards/npr7150.2d/`, read-only.

Documents may be combined, or kept in other systems, as the project's plans say (topic 7.18); a small project often keeps one plan.
