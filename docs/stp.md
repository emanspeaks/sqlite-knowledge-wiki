# Software test plan

How the software is tested (%[SWE-065]), after handbook topic 5.10.

## Test levels and types

Unit, integration, system, end-to-end and acceptance testing; the types of tests at each level (functional, regression, stress, performance, interface, boundary, coverage; for safety-critical software also fault insertion).

## Test classes and progression

How test cases are grouped, and in what order the groups run.

## Environment, sites and schedule

The test environment and its qualification (%[SWE-073]), the sites and people, and the schedule.

## Acceptance criteria and coverage

When testing is done; the code coverage measured and its targets (%[SWE-189], %[SWE-190]; for safety-critical software %[SWE-219]).

## Witnessing, data and risks

Test witnessing for safety-critical software; how data is recorded, reduced and analyzed; the risks of testing.
