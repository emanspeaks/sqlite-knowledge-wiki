# Software metrics

The measurements of the software and its work (%[SWE-090], %[SWE-093], %[SWE-094]), after handbook topic 5.05.

## Progress

Effort and schedule planned against actual; units designed, coded, tested and integrated; tests developed, run and passed; replans.

## Functionality and quality

Requirements in each build; problem reports by state and severity; peer reviews and audits and their findings; risks; requirements verified; static analysis results.

## Requirements volatility

The number of requirements, their changes by month, and the number still to be decided (%[SWE-200]).

```skein
coverage
```

## Characteristics

Languages, domain, size by category (new, modified, reused), and the use of computer resources.
