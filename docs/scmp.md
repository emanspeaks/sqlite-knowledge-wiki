# Software configuration management plan

How the software is kept under configuration management (%[SWE-079]), after handbook topic 5.06. With Skein, the items and documents are in git: baselines are its tags (`skein baseline`), and changes are its commits and pull requests.

## Organization and responsibilities

The project's organizations and the responsibilities of configuration management; the policies and directives that apply.

## Identification

The configuration items and how they are named (%[SWE-081]).

## Change control

How changes are requested, evaluated, authorized and tracked (%[SWE-080], %[SWE-082]).

## Status accounting

What is recorded of each item and change, and how it is reported (%[SWE-083]).

## Audits and reviews

Configuration audits (%[SWE-084]).

## Release management and delivery

How releases are built, described ([version description](vdd.md)) and delivered (%[SWE-085]).

## Generated code

The configuration of code generators, their inputs and outputs (%[SWE-146], %[SWE-206]).

## Schedule, resources and upkeep of this plan

The sequence of activities, the tools, and how this plan is kept up to date.
