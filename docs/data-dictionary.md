# Software data dictionary

The data of the software (handbook topic 5.07): standalone, in a database, or an appendix of another document.

## Channels and variables

Bus and channel mapping; input and output variables with their format, unit and definition; rate groups.

## Sensor data

Raw and calibrated data, units, definitions, and how raw data is reduced.

## Telemetry and recording

Telemetry formats and layouts per mode; data recorder formats.

## Commands

Onboard, ground and test commands: purpose, format, parameters; effector commands.

## Limits and scheduling

Operational limits; scheduling and communication between processors and tasks; partitioning.
