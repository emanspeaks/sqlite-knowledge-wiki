# Software assurance status report

The software assurance organization's report for a period (handbook topic 5.19): one per period, or this page kept current.

## Status

Progress, risks, schedule and help needed, at a glance.

## Work done and planned

Analyses, audits, products reviewed, tests witnessed and assessments, this period and next.

## Findings

Issues and non-conformances found by assurance, and their status.

## Metrics

At least those NASA-STD-8739.8B requires, with their trends.

```skein
coverage
```

## Watch items

Obstacles, improvement suggestions, risks.
